# Качалка

Торрент-клиент на libtorrent. Фоновая программа держит загрузки, команда `kachalka` ею управляет. Если команды нет в PATH, используй полный путь `~/.local/bin/kachalka`.

Всегда добавляй `--json`: так ответ можно читать без разбора текста.

## Команды

| Задача | Команда |
|---|---|
| Скачать magnet, .torrent-файл или ссылку на .torrent | `kachalka add --json "<источник>" [--to <папка>]` |
| Скачать только некоторые серии | `kachalka add --json "<источник>" --episodes 4,5` (также `4-6`, `S02E04`, `2x4`) |
| Какие файлы и серии в раздаче | `kachalka files --json <id>` |
| Докачать ещё серии / убрать / только эти / всё | `kachalka select --json <id> --episodes 6 --add`, `--remove`, без флага = только эти, `--all` |
| Разложить по папкам (план без изменений) | `kachalka sort --json <id\|all> [--dry-run]` |
| Разложить с поправкой | `kachalka sort --json <id> --title "Вспомнить всё" --year 1990 [--as movie\|series\|music\|book\|software\|other] [--season 2]` |
| Отменить раскладку | `kachalka undo --json <id или номер перемещения>` |
| Журнал раскладок | `kachalka moves --json` |
| Где я остановился, что посмотрено | `kachalka watching --json [id]` |
| «Я досмотрел 4-ю» / «не смотрел» | `kachalka watched --json <id> --episodes 4` (`--unwatched`; без `--episodes` — вся раздача, например фильм) |
| Режим «смотрю сериал» | `kachalka follow --json <id> [--ahead 2] [--keep-hours 24] [--no-cleanup] [--from 4]`; выключить — `unfollow` |
| Скачать сериал сразу в этом режиме | `kachalka add --json "<источник>" --follow [--ahead 2] [--episodes 4]` (`--episodes` тут = с какой серии начать) |
| Что можно убрать | `kachalka cleanup --json`; убрать — `kachalka cleanup --json --apply [--ids a,b]` |
| Что качается и раздаётся | `kachalka list --json` |
| Пауза / продолжить | `kachalka pause --json <id\|часть названия\|all>`, `kachalka resume --json …` |
| Убрать из списка, файлы оставить | `kachalka rm --json <id>` |
| Удалить вместе с файлами (в Корзину) | `kachalka rm --json <id> --files` |
| История | `kachalka history --json [--limit N]` |
| Скорость, КБ/с (0 = без ограничений) | `kachalka limit --json --down 5000 --up 500` |
| Настройки | `kachalka set --json download_dir "~/Movies/Торренты"`, `stop_seeding_at_ratio 1.0` (или `null`), `notify true` |
| Торренты через VPN или мимо | `kachalka vpn --json on\|off\|status` |
| Почему не качается (DHT, трекеры) | `kachalka diag` |
| Жива ли программа | `kachalka info --json` |

`id` — первые 8 символов info-hash из `list`. Фоновая программа запускается сама при первой команде.

## Правила

- `.torrent`-файл, который прислал владелец, передавай полным путём.
- Перед `rm --files` назови, что уйдёт в Корзину, и дождись «да». Просто `rm` без файлов можно без вопроса.
- Раскладка: после окончания загрузки Качалка сама кладёт файлы в `Фильмы/Название (Год)/`, `Сериалы/Название/Сезон N/`, `Музыка/`, `Книги/`, `Программы/`, `Другое/` внутри папки загрузок; раздача при этом продолжается. Названия берутся из имени раздачи (часто латиницей-транслитом: «Osnovnoi Instinkt»). Если видишь транслит или мусор — предложи нормальное название и примени через `sort --title … --year …`. Ошибся — `undo`.
- Серии: «скачай 4 и 5 серию» → `--episodes 4,5`. Если у magnet ещё нет метаданных, выбор применится сам, когда они придут. Не уверен, какие серии есть, — сначала `files`.
- Просмотр Качалка видит сама: позиции VLC (досмотрено = ≥90 % или до конца меньше 5 минут), какой файл сейчас открыт в плеере, дату открытия в Finder. Если владелец говорит «досмотрел», «начал 5-ю», «эту не смотрел» — отметь через `watched`.
- «Смотрю сериал X», «качай серии по мере просмотра» → `follow` (по умолчанию 2 серии наготове, просмотренные через 24 ч в Корзину). Владелец сам хотел, чтобы просмотренные серии в этом режиме убирались автоматически — это не требует отдельного подтверждения.
- `cleanup --apply` вне режима сериала — только после того, как показал список и владелец сказал «да».
- Отвечай по-человечески: название, процент, сколько осталось, к какому времени (МСК) закончится. Размеры в ГБ.
- Прогресс владелец видит и сам: значок «⬇ 57% 12 мин» в строке меню (SwiftBar).
- Режим по умолчанию — `vpn on`: торренты идут через VPN-туннель, который Качалка находит сама. Если в VPN включён kill switch, это осознанная защита: не предлагай его выключать и не включай `vpn off` без прямой просьбы (мимо VPN при kill switch ничего не пойдёт).
- Если magnet долго «ищу метаданные»: запусти `kachalka diag` и `kachalka vpn status`. Ноль узлов DHT и растущий `dht_messages_out_dropped` при `vpn on` — значит, туннель не найден или сменился: `kachalka restart` и снова `diag`.
- Ссылки и торренты бери только у владельца. Сам по трекерам не ищи.
- Журнал программы: `~/Library/Application Support/Kachalka/kachalka.log`.
